**медицинский домен** - работа с мед. данными, клиентами и мед персоналом
**финансовый домен** - работа с финансовыми данными, архивные данный по платежам
**аналитический домен** - обработка данных
**ИИ домен** - работа с мед. данными, иследования на основе ИИ

Разделение на домены позволит лучше структурировать поток данных. Агригация данных позволит быстрее подгатавливать отчетность и ускорит работу сервисов. Так же будет легче масштабировать систему и развивать каждую в своем направлении. 
Каждый домен имеют свои границы, следовательно за рамки домена выходит информация, которая имеет вес для аналитики и ИИ, что гарантирует безопасность и соблюдение ФЗ-152.
